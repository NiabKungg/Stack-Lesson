บทเรียนที่ 4: Stack (สแต็ก)

โครงสร้างข้อมูลแบบ LIFO (Last In, First Out) เข้าหลังสุดแต่ออกก่อนสุด และการประยุกต์ใช้งานในโลกความจริง

1. แนวคิดพื้นฐานของ Stack (LIFO)

Stack คือโครงสร้างข้อมูลที่เปรียบเสมือน "การซ้อนจาน" หรือ "การเก็บหนังสือทับกัน" ข้อมูลที่ถูกใส่เข้าไปหลังสุด จะถูกหยิบออกมาก่อนเสมอ (Last In, First Out - LIFO)

Core Operations (การทำงานหลัก)

  • push(int d) วางข้อมูลใหม่ทับลงไปบนสุดของ Stack
  • pop() หยิบข้อมูลตัวบนสุดออกไป (และลบออกจาก Stack)
  • top() / peek() ดูข้อมูลตัวบนสุดโดยไม่ต้องหยิบออก (ไม่ลบออกจาก Stack)

Stack Overflow: เกิดเมื่อพยายาม push ข้อมูลใส่ Stack ที่เต็มแล้ว

2. การสร้าง Stack: Array vs Linked List

กฎเหล็กของการทำ Stack คือ Operation หลักทั้งหมด (push, pop, top) ต้องทำงานได้ในเวลา O(1) เท่านั้น!

MyStackA (Array Implementation)

ใช้ตัวแปร top เป็นตัวเก็บค่า Index ช่องว่างถัดไป ที่จะวางข้อมูล (เริ่มต้นที่ 0)

public class MyStackA { int MAX_SIZE = 100; int[] stack = new int[MAX_SIZE]; int top = 0; // ชี้ไปที่ช่องว่างถัดไป // เอาของใส่ช่องว่าง แล้วขยับ top ขึ้น public void push(int d) { stack[top++] = d; } // ลด top ลงมา 1 ช่อง แล้วเอาค่าในช่องนั้นออก public int pop() { return stack[--top]; } public int top() { return stack[top-1]; } public boolean isEmpty() { return top == 0; } public boolean isFull() { return top == MAX_SIZE; } }

MyStackL (Linked List Implementation)

ใช้การเพิ่ม/ลบ Node ไว้ที่ ด้านหัว (head) เสมอ ซึ่งก็คือ addFirst() และ deleteFirst() ใน Linked List เพราะมันเร็ว O(1)

public class MyStackL { Node top = null; // ทำหน้าที่เหมือน head // แทรกไว้ด้านหน้าสุด (addFirst) public void push(int d) { Node p = new Node(d); p.next = top; top = p; } // ลบตัวหน้าสุดออก (deleteFirst) public int pop() { int d = top.data; top = top.next; return d; } public int top() { return top.data; } public boolean isEmpty() { return top == null; } public boolean isFull() { return false; } // ไม่เคยเต็ม! }

3. การประยุกต์ใช้งาน Stack (Applications)

3.1 การแปลงเลขฐานสิบเป็นฐานสอง (Decimal to Binary)

เมื่อเรานำตัวเลขมาหาร 2 ไปเรื่อยๆ และเก็บเศษ (Remainder) ไว้ เศษตัวแรกที่ได้คือบิตสุดท้าย (LSB) ส่วนเศษตัวสุดท้ายที่ได้คือบิตแรก (MSB)

คุณสมบัติ LIFO ของ Stack จึงตอบโจทย์มาก เพราะเราเก็บเศษเข้า Stack ไปเรื่อยๆ แล้วค่อย pop() ออกมาเรียงกันตอนจบ จะได้เลขฐานสองที่ถูกต้องพอดี!

public void printBinary(int decimal) { Stack<Integer> s = new Stack<>(); while(decimal > 0) { s.push(decimal % 2); // เก็บเศษ decimal /= 2; // หารสอง } while(!s.isEmpty()) { System.out.print(s.pop()); // ปริ้นออกแบบย้อนกลับ } }

3.2 การคำนวณ Postfix หรือ Reverse Polish Notation (RPN)

สมการคณิตศาสตร์ปกติแบบ Infix (เช่น 3 + 4 * (7 - 5)) ต้องใช้วงเล็บเพื่อจัดลำดับ แต่ถ้าแปลงเป็น Postfix (RPN) เครื่องหมายจะอยู่หลังตัวเลข เช่น 3 4 7 5 - * + ซึ่ง Stack สามารถคำนวณได้ในเวลา O(n) จากซ้ายไปขวาโดยไม่ต้องใช้วงเล็บเลย!

กฎของ RPN Computation:
  1. อ่าน Token ทีละตัวจากซ้ายไปขวา
  2. ถ้าเป็นตัวเลข: ให้ push() ลง Stack
  3. ถ้าเป็นเครื่องหมาย (Operator):
    • ให้ pop() ตัวบนสุดออกมาเก็บไว้ในตัวแปร b (ตัวหลัง)
    • ให้ pop() ตัวถัดมาออกมาเก็บไว้ในตัวแปร a (ตัวหน้า)
    • นำมาคำนวณ a operator b (สำคัญ: a ต้องอยู่หน้า b เสมอเวลาลบหรือหาร)
    • นำผลลัพธ์ที่ได้ push() กลับลงไปใน Stack
  4. เมื่ออ่านจบ ค่าสุดท้ายใน Stack คือคำตอบ!
public int computeRPN(String[] tokens) { Stack<Integer> stack = new Stack<>(); for (String t : tokens) { if (t.equals("+")) { stack.push(stack.pop() + stack.pop()); } else if (t.equals("-")) { int b = stack.pop(); int a = stack.pop(); stack.push(a - b); } else if (t.equals("*")) { stack.push(stack.pop() * stack.pop()); } else if (t.equals("/")) { int b = stack.pop(); int a = stack.pop(); stack.push(a / b); } else { // เจอตัวเลข ให้แปลงและ push stack.push(Integer.parseInt(t)); } } return stack.pop(); }
